# 🧠 Multi-Domain Support Triage Agent

A terminal-based intelligent support agent that processes support tickets across multiple platforms and generates **safe, grounded, and actionable responses** using only trusted documentation.

---

## 🚀 Overview

This system is designed to simulate a real-world **support triage pipeline**, handling tickets across:

- HackerRank Support
- Claude Help Center
- Visa Support

For each ticket, the agent:
1. Classifies the request
2. Determines the product domain
3. Evaluates risk and safety
4. Retrieves relevant documentation
5. Generates a grounded response OR escalates
